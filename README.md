# Self-Commissioning PMSM Drive

A model-based PMSM drive project focused on field-oriented control (FOC),
motor parameter identification, and self-commissioning control strategies.

## Project Goal

The objective of this project is to investigate how PMSM parameter uncertainty
affects motor-control performance and to develop a self-commissioning approach
capable of identifying motor parameters and automatically tuning the control loops.

## Planned Development

- PMSM mathematical model in the dq reference frame
- Clarke and Park transformations
- Field-oriented control
- Current and speed PI controllers
- Parameter sensitivity analysis
- Motor parameter identification
- Automatic controller tuning
- Embedded C implementation
- Experimental validation on a low-voltage motor-drive platform

## Current Status

**Phase 1 — PMSM Mathematical Modeling**

Initial implementation of the PMSM dq-axis model is in progress.
